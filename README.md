# 🏯 3D漢字タワー 〜百層の試練〜

Three.js で描画された3Dの巨大な螺旋古塔を駆け上がり、100層の頂上を目指す本格3Dアクション漢字学習ゲームです。  
小学校1年生から6年生で習う**全1026漢字**を完全網羅し、キーボード操作のみで爽快にプレイしながら漢字の読み書きをマスターできます。

---

## 🎮 ゲームの特徴

1. **塔の周りを駆け上がる3Dスパイラルアスレチック**
   - 巨大な古塔の外周に張り巡らされた螺旋状の足場を、ジャンプ・ダッシュを駆使して駆け上がります。
   - 階層ごとに空や足場、舞い散る粒子（桜、紅葉、蛍、雪、黄金）が変化する美しいバイオーム演出。

2. **小学校1〜6年生の全1026漢字に完全対応**
   - 文部科学省の学習指導要領（現行配当表）に完全準拠：
     - **1〜15層**: 小学1年生（80字）
     - **16〜35層**: 小学2年生（160字）
     - **36〜55層**: 小学3年生（200字）
     - **56〜75層**: 小学4年生（202字）
     - **76〜90層**: 小学5年生（193字）
     - **91〜99層**: 小学6年生（191字）
     - **100層**: 天空の天守閣・全学年総力決戦！

3. **多彩な問題レパートリー（読み書き総合学習）**
   - 訓読み問題（くんよみ）
   - 音読み問題（おんよみ）
   - 画数問題（総画数当て）
   - 対義語問題（反対の意味の漢字）
   - 漢字選択問題（読みから正しい漢字を特定）
   - 正解時・不正解時ともに、音訓・画数・学年の詳しい解説が表示されます。

4. **動く敵・トラップ・ギミック満載**
   - **墨妖怪「スミまる」**: 足場を往復。頭を踏みつけると倒せる！
   - **浮遊鬼火**: 空中を浮遊・旋回。くぐるか飛び越えよう。
   - **動く足場**: 左右にスイングする足場。
   - **崩れる足場**: 乗ると1.2秒後に崩落（3秒後に復活）。
   - **スーパージャンプ台**: 高く跳び上がる跳躍パッド。
   - **トゲ罠**: 주기的に針が飛び出す危険な床。
   - **勾玉・ハート**: スコア加算やHP回復アイテム。

5. **HPシステム＆安心のリスポーン**
   - 体力（HP）ゲージ搭載。敵やトゲに接触するとHP減少。
   - 漢字クイズに正解すると **HP回復（+30）**！勉強するほど生き残りやすくなります。
   - 足場から落下しても直前の安全地点へ自動復帰（ゲームオーバー時もその階から即リトライ可能）。
   - クリア階層は自動保存され、「つづきから」プレイ可能。

6. **キーボードのみで完全操作（マウス不要）**
   - 移動からクイズの解答（1〜4キー）、メニュー操作まですべてキーボードで完結します。

7. **Web Audio API によるプロシージャル和風サウンド**
   - 外部音声ファイル不要。BGMや効果音（ジャンプ、着地、敵撃破、ファンファーレ等）を即時生成。

## ⌨️ 操作方法（キーボード専用）

| 操作 | キー |
| :--- | :--- |
| **走る（塔を周回）** | `A` / `D` または `←` / `→` |
| **ジャンプ** | `Space` または `W` / `↑` |
| **ダッシュ（加速）** | `Shift` を押しながら移動 |
| **しゃがみ / 空中急降下** | `S` または `↓` |
| **クイズ選択肢解答** | `1`, `2`, `3`, `4`（テンキーも可） |
| **次へ進む / 決定** | `Enter` または `Space` |
| **復活・再挑戦** | `R` または `Enter` |
| **つづきから再開** | `C`（タイトル画面） |
| **サウンドON/OFF** | `M` |
| **一時停止（ポーズ）** | `ESC` または `P` |
| **操作一覧表示** | `H` |
| **デバッグ用階層スキップ** | `N`（次階へ） / `B`（前階へ） |

## 🚀 GitHub Pages への公開

本リポジトリには GitHub Actions ワークフロー (`.github/workflows/deploy.yml`) が含まれています。  
リポジトリの `Settings` > `Pages` にて **Source: GitHub Actions** を選択することで、プッシュ時に自動ビルド・デプロイされます。

```bash
git add .
git commit -m "feat: Add 3D Kanji Tower game"
git push origin main
```
